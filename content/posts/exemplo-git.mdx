Histórico legível acelera review e incident response. Cada commit deve contar uma história completa e reversível.

## Mensagem em duas frases

A primeira linha resume a intenção; o corpo explica o porquê quando não é óbvio.

```text
fix(blog): redirect invalid page to last valid page

Keeps view=grid when clamping out-of-range page numbers.
```

Rebase local antes do push mantém a linha do tempo linear sem reescrever trabalho já compartilhado.
