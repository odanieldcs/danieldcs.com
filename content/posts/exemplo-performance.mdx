Performance é experiência: página que responde cedo mantém leitor na listagem e no artigo.

## Imagens com tamanho certo

`next/image` com `sizes` evita baixar pixels demais.

```tsx
<Image
  src="/media/posts/exemplo-performance.png"
  alt="Capa do artigo"
  width={800}
  height={450}
  sizes="(min-width: 64rem) 20rem, 100vw"
/>
```

Server Components reduzem bundle client; lazy load só onde interação exige hidratação.
