Menos JavaScript no cliente significa menos hidratação, menos estado duplicado e páginas mais rápidas.

## `'use client'` com parcimônia

Mova interatividade para a borda — providers, toggles, formulários — e deixe dados no servidor.

```tsx
export default async function Page() {
  const items = getAllPosts()
  return <BlogView posts={items} />
}
```

Serializar props simples (strings, números) entre server e client evita surpresas com `Date` ou funções.
