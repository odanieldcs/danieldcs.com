API pública é produto: mudança breaking exige migração, comunicação e tempo.

## Erros estruturados

Corpo de erro consistente acelera debug no cliente.

```json
{
  "error": {
    "code": "post_not_found",
    "message": "Post not found: slug"
  }
}
```

Campos opcionais novos são compatíveis; remover ou renomear campos exige versão ou feature flag.
